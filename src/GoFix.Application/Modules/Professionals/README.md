# Professionals / Application

Valida la edición completa del perfil y expone consultas de catálogos activos. El contrato de edición recibe descripción, identificadores de cobertura y versión en base64. Las listas repetidas o vacías y el contenido inválido producen errores de campo.

`DirectoryService` coordina la búsqueda pública con `IProfessionalDirectory` y el contrato de reputación de Valoraciones. Valida página, tamaño y filtros y entrega únicamente los campos de `PublicProfessional`.
